# GSP

A PSP-style handheld that runs in the browser, made by getnsh.

**Play it:** https://getnsh.github.io/gsp/

This repository holds only the built page — one `index.html` with everything inlined — and its
link-preview image. It is published by `tools/publish.py` from the private source repository.

A personal tribute to the PlayStation Portable. Not affiliated with, endorsed by, or connected to
